# Aster Home Elevators website

Static site, ready for GitHub Pages.

## Publish
1. Create a repository and upload everything in this folder (keep `images/` and `assets/`).
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, folder `/ (root)`.
3. For www.asterhomeelevators.com: add the domain under Settings → Pages → Custom domain, then point the domain's DNS to GitHub Pages.
